# 한글 표현 스타일 가이드

앱에 들어가는 한국어(원문, 추천 표현, 설명, 화면 문구)를 쓸 때 기준이에요. 주간 콘텐츠 루틴도 이 문서를 따라요.

## 분야별 톤

| 분야 | 목표 톤 | 기준 |
|---|---|---|
| 마케팅·광고 | 세련된 브랜드 카피 | 설명 대신 장면, 재촉 대신 사실, 형용사 대신 숫자와 구체적인 사물 |
| 비즈니스·이메일 | 깔끔한 업무 한국어 | 정중하되 군더더기 없이. 번역투 빼기 |
| 일상 회화 | 요즘 실제로 쓰는 구어 | 자연스러운 말. 유행어를 억지로 넣지 않기 |
| 여행·안내문 | 실제 안내문·방송 말투 | "~해 주시기 바랍니다"처럼 현장에서 쓰는 격을 그대로 |
| 앱 화면 문구 | 해요체, 짧고 능동형 | 토스 UX 라이팅 원칙처럼 명확·간결·긍정형 |

분야를 섞지 않아요. 여행 안내 방송을 광고 카피처럼 쓰면 오히려 틀린 격이 돼요. 이 앱은 격(register)을 배우는 곳이라 더 그래요.

## 마케팅 카피에서 피할 것 → 바꿀 것

| 피할 표현 (상투적) | 이유 | 이렇게 |
|---|---|---|
| 지금 바로 만나보세요 | 모든 광고에 쓰여서 아무 말도 안 하는 것과 같아요 | 오늘, 공개합니다 / 구체적인 행동(입어 보세요, 한 입 드셔 보세요) |
| ~을 느껴보세요, 경험해 보세요 | 감각을 명령해요 | 감각을 장면으로: "한 모금에, 가을이 먼저 도착했어요" |
| 소중한 의견, 고객님의 소중한 | 형식적인 인사말 | "써 보니 어떠셨어요? 한 줄이면 충분해요" |
| 놓치지 마세요!, 서두르세요! | 재촉, 느낌표 남발 | 사실로 희소성 전하기: "오늘 자정, 혜택이 닫혀요", "딱 300개만 만들었어요" |
| 완벽한, 최고의, 특별한 | 증명 없는 최상급 | 구체적인 근거나 장면 |
| 작은 선택이 큰 변화를 만든다고 믿습니다 | 누구나 쓰는 추상적인 다짐 | 구체적인 사물로: "오늘 고른 칫솔 하나가 내일의 바다를 바꿉니다" |
| 한정! 무료! 이벤트! | 전단지 느낌 | 담백하게: "주말 동안만, 50달러부터 무료 배송" |

## 번역투 걷어내기

| 번역투 | 자연스럽게 |
|---|---|
| ~을 통해 | ~로, ~해서 |
| ~에 대한 의견 | ~ 보시고 의견 / ~에 의견 |
| ~을 가진 | ~이 있는 |
| ~하는 것이다 | 문장을 짧게 끊기 |
| 당신 | 빼거나 "나"로 (광고에서 "당신"은 거리감) |
| 관련해 | ~ 건으로 |
